SuliNOC - network operations prototype

Open index.html in a browser. It is one self-contained file (hero images are embedded),
so it works by double-clicking. Fonts (Newsreader, Manrope, IBM Plex Mono) load from
Google Fonts, so they need an internet connection; fallbacks are used offline.

All telemetry, tower positions, incidents and crew movements are SIMULATED.
Nothing real is monitored or dispatched.

assets/ holds the two hero layers (city background and tower cutout) for reuse.
Check you have the right to use the source photos before publishing publicly.

Shortcuts: / search, [ collapse sidebar, Esc close panel.
